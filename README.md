# cv.aidenhovren.com

This repository contains the source for **cv.aidenhovren.com** — a clean, fast, and intentionally minimal web-based CV for Aiden Hovren.

The goal of this project is simple:
- Present a professional résumé in a format that is **human-readable**, **machine-readable**, and **future-proof**
- Maintain full ownership and control over layout, content, and distribution
- Enable easy export to PDF without relying on third-party résumé builders

This is not a résumé template.  
It is a living document.

---

## Philosophy

Most résumés are treated like static artifacts. This one is treated like software.

- **Versioned** — changes are tracked, intentional, and reversible  
- **Composable** — content and presentation are cleanly separated  
- **Portable** — web first, printable second, PDF last  
- **Honest** — no fluff, no keyword stuffing, no corporate cosplay  

The format favors clarity over cleverness and signal over noise.

---

## Features

- Semantic HTML structure for accessibility and ATS compatibility
- Print-optimized CSS for clean PDF exports
- Fully responsive layout
- No frameworks required at runtime
- Easy to fork, adapt, or extend

---

## Tech Stack

- HTML5
- CSS (print + screen styles)
- Optional build tooling depending on deployment target

No external dependencies are required to view or use the résumé.
